# us_zip_codes.csv

US ZIP code → state + centroid (lat/lng), used for discovery geography
(Selected States, ZIP + radius) and to turn a shopper's GPS position into a ZIP.

Source: GeoNames postal code data (https://download.geonames.org/export/zip/US.zip),
licensed under Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/).
Trimmed to zip, state, lat, lng (coordinates rounded to 4 decimals).
